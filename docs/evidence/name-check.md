# "Pyaww" name check (2026-10-17)

> Historical record (2026-10-17). Kept as evidence; not updated.

Owner-requested collision check before Phase 4 (SPEC §1). Agent-run, best
effort: web/GitHub/registry searches plus DNS and `whois` for the obvious
domains. Trademark screening was via public USPTO records (Justia mirror) —
not a legal clearance search. The owner makes the final call.

## What was searched

- Web search for "Pyaww" (general and software contexts).
- GitHub (repos/users) and the Python Package Index (PyPI).
- App Store listings.
- `whois` + DNS for `pyaww.com` and `pyaww.app`.
- Trademarks: Justia Trademarks (USPTO records), best effort.

## Findings

1. **One exact-spelling software match, dormant.** A PyPI package named
   `pyaww` (v1.0.0, 2022, MIT) — a small API wrapper for PythonAnywhere.
   Single release, no activity since; unrelated field (HTTP API tooling,
   not dictation). No practical conflict for a macOS app.
2. **No active product or popular project named "Pyaww."** The GitHub
   search surfaces only the dormant package above; a personal account
   handle `pooyaww` exists (a person, not a product).
3. **App Store: no app named "Pyaww."** Closest neighbors are unrelated
   pet/dog apps with similar-sounding names ("pawy", a few "Paww …" dog
   apps by different developers) — a different category entirely.
4. **No "PYAWW" trademark found.** Nearest live US mark is **PAWW**
   (Paww LLC, class 009 "electrical and scientific apparatus", which can
   cover software). "Pyaww" differs in spelling, but if the app is ever
   released publicly under this name, this is the one item a professional
   clearance search should re-check first.
5. **Domains:** `pyaww.com` is unregistered (`whois`: "No match").
   `pyaww.app` could not be verified (this machine can't reach the Google
   registry whois); it does not resolve in DNS today. Neither conflicts.

## Conclusion

Low risk for personal use and small-circle sharing: keep **Pyaww**. If a
public release ever happens, revisit finding 4 (PAWW) with a proper
trademark clearance search before committing to the name.
